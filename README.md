# PaedsMe prototype

Static, click-through prototype of the PaedsMe family app, Find care, GP referral, Diagnostics hub and Clinic tools screens. Everything in it is synthetic: no real patients, clinicians or clinics.

Published with GitHub Pages from this repository. Source of truth is `paedsme/prototype` on the `paedsme/handoff` branch of the ADHDme repository; copy the three files here to update the live page.
